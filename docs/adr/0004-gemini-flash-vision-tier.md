# Google Gemini Flash for Tier 2 Vision Automation

To navigate and automate arbitrary desktop GUI applications without incurring heavy latency or expensive per-step token charges, the Tier 2 Vision Agent uses Google Gemini 3 Flash / Flash-Lite. Gemini Flash provides sub-800ms multimodal inference and high-fidelity coordinate detection at approximately $0.25 per million tokens, delivering production-grade screen perception at a fraction of the cost of legacy frontier models.
