# OpenRouter Multimodal Vision & Local OpenAI-Compatible Endpoints (Tier 2)

To navigate and automate arbitrary desktop GUI applications without incurring heavy latency or expensive per-step token charges, the Tier 2 Vision Agent uses OpenRouter's OpenAI-compatible HTTP API (`qwen/qwen3-vl-8b-instruct` by default, with automatic fallback to `google/gemini-3.1-flash-lite` and `qwen/qwen3-vl-30b-a3b-instruct`), or any user-configured OpenAI-compatible local endpoint (e.g., Ollama, LM Studio, vLLM). Combined with Windows UI Automation (UIA) Set-of-Marks and TypeSafe Jev click-racing, it delivers fast, DPI-aware screen perception across multi-monitor setups at ~$0.0003/call or completely free locally.
